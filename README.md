# Welcome to LumaMart

LumaMart is a modern multi-store commerce demo built with Next.js, React, Redux Toolkit, Tailwind CSS and Prisma.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

The project uses demo data from `assets/assets.js`, so the interface can be explored without configuring a production database or payment provider.

## Main routes

- `/` storefront home
- `/shop` product catalog
- `/product/[productId]` product details
- `/cart` shopping cart and demo checkout
- `/orders` customer order history
- `/create-store` seller application
- `/pricing` seller plans
- `/login` demo sign-in
- `/admin` admin dashboard
- `/admin/stores` store management
- `/admin/approve` seller application review
- `/admin/coupons` coupon management
- `/store` seller dashboard
- `/store/add-product` product creation
- `/store/manage-product` product management
- `/store/orders` seller order management
